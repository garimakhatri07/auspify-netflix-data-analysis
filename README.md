# Netflix Data Analysis | Auspify Technologies Internship

## About the Project

As part of my Data Analysis internship at Auspify Technologies, I worked on a Netflix dataset to explore its content and understand different patterns through data analysis.

I used Python to clean the dataset, perform analysis, create visualizations, and identify useful observations about Netflix Movies and TV Shows.

The project is divided into four tasks, covering different parts of the dataset.

## Tasks Completed

### 1. Netflix Data Cleaning & Preparation
- Checked the dataset for missing and duplicate values.
- Handled unavailable values in the Director and Country columns.
- Standardized categorical values and cleaned text formatting.
- Exported the cleaned dataset for further analysis.

### 2. Country-Wise Netflix Content Analysis
- Explored the distribution of Netflix content across countries.
- Identified the top 10 countries based on content count.
- Compared country-wise content contributions using charts.
- Observed which countries had a larger representation in the dataset.

### 3. Netflix Release Year Trend Analysis
- Analysed the number of titles across different release years.
- Identified years with higher content counts.
- Compared release-year trends for Movies and TV Shows.
- Used charts to understand changes in the distribution of content over time.

### 4. Content Rating & Genre Analysis
- Examined the distribution of different content ratings.
- Explored the most common genres in the dataset.
- Compared genre distribution between Movies and TV Shows.
- Created visualizations to present the findings.

## Tools & Technologies

- **Python** – Data analysis
- **Pandas** – Data cleaning and manipulation
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Jupyter Notebook** – Writing and executing analysis

## Dataset Information

The project uses a Netflix titles dataset containing information about Movies and TV Shows, including title, director, country, release year, rating, duration, and genre.

- Original dataset: 8,790 rows and 10 columns.
- Cleaned dataset: 8,790 rows and 10 columns.
- Unavailable Director and Country values were retained as missing rather than replaced with assumed values.
